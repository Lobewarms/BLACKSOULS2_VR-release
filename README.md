# BLACK SOULS II VR (비공식 팬 모드)

BLACKSOULS II를 1인칭으로 플레이하는 비공식 팬 모드입니다.
원작 제작자·배급사와는 관계가 없으며, 원작 게임 파일은 들어 있지 않습니다. 원작 게임이 있어야 합니다.

## 받기
- 최신 버전: [BLACKSOULS_VR_2026.10.21-10.zip](BLACKSOULS_VR_2026.10.21-10.zip) (파일을 연 뒤 Download)
- 설치·조작법은 zip 안의 README / CONTROLS를 보세요 (한국어·English·日本語·中文).

## 이용 조건
- 무료로 받아 플레이할 수 있습니다.
- 플레이 영상·방송은 자유롭게 해도 됩니다 (수익 창출 포함). 원작의 방송 규정은 원작 제작자의 안내를 따라 주세요.
- 수정본은 무료로, 이 페이지를 출처로 밝히고, 원본이 아닌 수정본임을 표시하면 배포할 수 있습니다.
- 원본을 그대로 공유할 때는 파일 대신 이 페이지 링크를 공유해 주세요.
- 판매(유료 배포)와 원작 게임 파일을 넣은 배포는 허용하지 않습니다.
