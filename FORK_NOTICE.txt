BLACK SOULS II VR - modified community fork

WINDOWS PLAYERS: download BLACKSOULS_VR_Setup_0.2.1.exe from the release assets.
Run setup, open BLACK SOULS II VR from the Start menu, select your original game
folder, then click Launch. No manual ZIP extraction or developer tools needed.
Connect your PC VR headset before launching, then click ENTER VR in the game window.
The portable ZIP remains available for users who prefer manual extraction.


This is a MODIFIED version, not the original release by Lobewarms.
Original: https://github.com/Lobewarms/BLACKSOULS2_VR-release
Fork: https://github.com/dimasma0305/BLACKSOULS2_VR-release

This fork uses an npm workspace with Vite, npm-managed Three.js and WebXR assets,
and an installable Python server package. It adds lint, regression tests,
portable packaging and CI/CD. Generated releases retain the launcher layout.
See upstream.json in the release (vendor/launcher/upstream.json in source) for
upstream provenance. Dependency versions are recorded in package-lock.json.

The Windows launcher is the unchanged upstream binary. Launcher source was
not included in the upstream release, so this fork does not rebuild it.
The launcher may offer upstream updates; installing them can replace fork files.
